# dca

Monitor DCA — app estática (`index.html`, sin build) pensada para
GitHub Pages. Los datos del usuario se guardan en el repo privado
aparte `dca-data`, vía la API de GitHub desde el propio navegador.

Ver [`NOTAS_TECNICAS.md`](./NOTAS_TECNICAS.md) para la arquitectura de
persistencia y sincronización.
